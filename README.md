# ASHISH — Video Editor Portfolio

A responsive cinematic portfolio site for Ashish.

## Run locally
Open `index.html` in a browser.

## Showreel asset
Place the supplied portfolio video at `assets/ashish-showreel.mp4`. The page already references that path in its video player.

## Publish
Deploy this repository as a static site with Vercel, Netlify, or GitHub Pages. Keep the `assets` directory beside `index.html`.
